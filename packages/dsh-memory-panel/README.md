# @restregular/dsh-memory-panel

DSH 记忆管理面板：设置页里的「记忆」区块，可浏览/搜索/编辑/删除记忆，并手动启停本地向量服务。

## 安装

```bash
pnpm add @restregular/dsh-memory-panel
```

面板的数据来自核心包 **@restregular/dsh-memory** 提供的 `memory` 服务；未安装核心包时面板仍会出现，但会提示「memory provider 未加载」，不会造成启动失败。

## 使用

设置页 →「记忆」：

- 概览卡片：记忆条数 / 作用域数 / 待嵌入向量数
- 搜索：按内容、类型、标签过滤；作用域下拉切换
- 每条记忆**默认折叠**（单行预览 + 字数），点标题行展开看全文，展开后可编辑（内容/类型/标签/重要度）或删除
- 向量服务开关：一键启停本地嵌入服务；外部启动的实例会置灰并说明原因，不会被误杀
